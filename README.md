# 🏨 Hotel Website Project

A modern, responsive landing page for a hotel designed to showcase features, room highlights, location details, and contact options.

---

## ✨ Features

* 📱 **Fully Responsive Layout:** Built to look great on desktop, tablet, and mobile devices.
* 📍 **Interactive Location Map:** Embedded Google Map for easy navigation.
* 🖼️ **Property Showcase:** Sections for displaying hotel amenities, rooms, and images.
* 📞 **Contact & Social Links:** Clear call-to-action options for bookings and inquiries.

---

## 🛠️ Tech Stack

* **HTML5** – Semantic page structure
* **CSS3** – Custom styling & layout design
* **JavaScript** – Interactivity (if applicable)
